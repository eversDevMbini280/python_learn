║   ## Ε. Comment utiliser ce dépôt                                                         ║
║                                                                                           ║
║   1. Choisir un chapitre selon la notion à apprendre.                                    ║
║   2. Lire les ressources ou la documentation associée.                                   ║
║   3. Faire les exercices : facile, moyen, difficile.                                     ║
║   4. Terminer avec le projet de fin de chapitre.                                         ║
║   5. Modifier, tester, casser et recommencer.                                            ║
║                                                                                           ║
║   Exécuter un fichier : python "chemin/vers/le/fichier.py"                              ║

║   ## Ζ. Contribuer                                                                        ║
║                                                                                           ║
║   Les contributions sont les bienvenues : exercices, corrections, ressources,             ║
║   documentation, liens utiles, vidéos ou améliorations de structure.                      ║
║                                                                                           ║
║   Avant toute contribution :                                                              ║
║   1. Créez votre propre branche.                                                          ║
║   2. Respectez l'architecture du dépôt.                                                   ║
║   3. Ajoutez vos fichiers dans le bon chapitre.                                           ║
║   4. Nommez clairement vos dossiers et fichiers.                                          ║
║   5. Expliquez ce que vous avez ajouté dans votre pull request.                          ║
║                                                                                           ║
║   Types de contributions :                                                                ║
║   - Exercice : Ajouter un exercice sur les boucles for et while.                         ║
║   - Documentation : Ajouter une explication simple.                                       ║
║   - Ressource : Ajouter un lien vers une vidéo pédagogique.                              ║
║   - Correction : Corriger une faute ou un bug.                                           ║
║   - Projet : Ajouter un mini-projet de fin de chapitre.                                  ║
║                                                                                           ║
